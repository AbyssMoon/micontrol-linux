MI Control для Linux — переносная сборка
========================================

Ничего не устанавливает: Qt, QML и программы лежат в этой папке.
Подробности и исходники: https://github.com/AbyssMoon/micontrol-linux

1. Интерфейс без железа (root не нужен):
       ./run.sh --mock

2. Модуль ядра acpi_call (через него идут вызовы прошивки).
   run.sh загружает его на время работы и выгружает при выходе:
     - если пакет acpi_call уже стоит в системе — используется он;
     - иначе соберите модуль в этой папке: ./build-acpi_call.sh
       (нужны заголовки ядра: kernel-devel / linux-headers, gcc, make).
   При включённом Secure Boot собранный модуль не загрузится без подписи.

3. Первая проверка на ноутбуке — ТОЛЬКО ЧТЕНИЕ:
       ./run.sh probe
   Ожидается: байт 1 ответа — 80 (успех); режим — в байте 4
   (02 тихий, 03 турбо, 04 максимум, 09 авто); микрофон, лимит заряда
   и здоровье батареи — в байте 6. E0 в байте 1 — функция не поддерживается.

4. Запуск (демон от root + окно):
       ./run.sh
   Закрытие окна убирает его в трей. Выход — правый клик по значку → «Выход»;
   тогда демон останавливается, модуль выгружается.

Где что лежит:
   state/state.json  — сохранённые настройки
   state/daemon.log  — лог демона

Отладка (пока ./run.sh запущен, в другом терминале):
   MICONTROL_SOCKET=/run/micontrol-test.sock ./bin/micontrol status
   sudo ./bin/micontrol raw get 0x10 0x02       — произвольное чтение

Лимит заряда хранит сама прошивка: он действует и после выхода из программы.
Вернуть 100% — выбрать «без лимита» перед выходом.
